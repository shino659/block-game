# ブロックゲーム

シンプルなテトリス風のブロック落ちゲームです。ブラウザだけで遊べます。

## 遊び方
1. `index.html` をブラウザで開きます。
2. キー操作でブロックを動かしてラインを消しましょう。

### 操作
- ← → : 左右移動
- ↑ : 回転
- ↓ : ソフトドロップ
- Space : ハードドロップ
- リスタートボタン : いつでも新しいゲームを開始

## 仕組み
- 10x20 のグリッドをキャンバスに描画しています。
- テトリミノを落下させ、着地するとライン消去・スコア計算・レベルアップを行います。
- レベルが上がるほど落下速度が速くなります。

## 開発メモ
スタンドアロンの HTML/CSS/JS で完結しています。ローカルで編集しながらブラウザをリロードすると反映されます。
